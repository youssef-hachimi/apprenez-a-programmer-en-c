## 🎯 About

This project is a collection of C programming exercises and examples designed for beginners learning the C language through the OpenClassrooms platform. The repository includes both C source code files and a web interface to navigate through the learning materials.

## 🚀 Getting Started

### Prerequisites

To work with the C code in this repository, you'll need:

- **C Compiler**: GCC (GNU Compiler Collection) or any standard C compiler
  - Windows: [MinGW](http://www.mingw.org/) or [TDM-GCC](https://jmeubank.github.io/tdm-gcc/)
  - macOS: Install Xcode Command Line Tools
  - Linux: GCC is usually pre-installed

- **Text Editor or IDE** (optional but recommended):
  - [Visual Studio Code](https://code.visualstudio.com/)
  - [Code::Blocks](http://www.codeblocks.org/)
  - [CLion](https://www.jetbrains.com/clion/)
  - Any text editor of your choice

## 📚 Topics Covered

This course typically covers fundamental C programming concepts including:

- Variables and data types
- Operators and expressions
- Control structures (if/else, loops)
- Functions and modular programming
- Arrays and strings
- Pointers
- Structures
- File I/O
- Dynamic memory allocation
